Card Strike

Elemental strategy card battles with a Python + Pygame game client and AI-driven CPU logic.

View Repository

Important note

This GitHub Pages site can host static project content, but the current game itself is not browser-playable yet. The game is built with Python, Pygame, and a Flask launcher, while GitHub Pages only serves static HTML, CSS, and JavaScript.

What is in this repo

The project includes the main desktop game, AI combat logic, card data, assets, and a lightweight web launcher.

How to play right now

Clone the repository, install Python + Pygame, and run python main.py locally.

To make it playable on Pages

The next step would be a browser port, such as rewriting the frontend in JavaScript or trying a Pygame WebAssembly path like pygbag.
